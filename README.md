# Choose Your Own Adventure Game

A text-based Python adventure game where your choices shape the story, challenges, and ending.

## About

This project started as a simple choice-based Python game and gradually grew into a complete adventure with branching paths, combat, exploration, puzzles, inventory, and multiple endings.
The goal was to practice Python fundamentals by turning them into an actual playable project rather than isolated exercises.

## Features

- Branching story with different paths
- Dragon battle with randomized turn order
- Player and enemy health system
- Sword and shield mechanics
- Inventory system
- Castle exploration
- Keys and locked doors
- Puzzle-based choices
- Multiple win and game-over conditions
- Randomized game elements
- Different outcomes based on player decisions

## Python Concepts Practiced

- Variables and data types
- Conditional statements
- `while` loops
- Functions
- Lists and dictionaries
- User input and validation
- `random`
- Recursion
- `functools.lru_cache`
- Game-state management
- Basic problem-solving and logic
